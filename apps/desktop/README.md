# hatto_desktop

macOS and Linux shell for Hatto. This build opens a local collection with
the desktop call profile and shows the AGPL notices. The study flow and the
editor are not in this app yet.

There is no Windows target. App Sandbox is off until the release change
that signs and notarizes the app.
